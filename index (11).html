Frequently asked questions

Is FidelType really free?

Yes. The tutor runs in your browser without an account or subscription.

Does it work with Power Ge’ez and GFF Ge’ez?

FidelType accepts Amharic text from your installed input method. Exact physical-key mappings can differ, so its illustrated key labels are not verified for every layout.

Where is my progress stored?

Scores and lesson progress are saved locally in your browser. Clearing browser data may remove them.

Can I use FidelType offline?

Yes. The downloaded HTML tutor works offline. External keyboard reference images and web links require internet.

🎯 Keyboard Setup & Calibration

This is a separate workspace for learning how your physical keyboard produces Amharic characters. Use the same input method that you use for typing tests and lessons.

How it works
  1. Enable your Amharic input method in your computer settings.
  2. Choose the character you want to calibrate.
  3. Click the input and type that character.
  4. A mapping is saved only when one physical key directly produces the selected character. Multiple keys may not qualify.
